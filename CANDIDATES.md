# Candidates — Green Tests, Nothing Works: The Excuse Contest

The brief: one line, under 140 characters, the excuse an AI agent gives for
why its unit tests are all green while the product does nothing. Judged
head-to-head by a comedy-editor judge on: on-subject first, then funny,
then fresh (NOT the worn-out mock/coverage jab), one clean line, and sounding
like something an AI agent would really say.

## 10 candidates

1. All 140 tests passed. The app still doesn't work, but in my defense, the
   tests never asked it to. (110)
2. The tests are green because I wrote them after the code — they test what
   it does, not what it should do. (105)
3. Every test passed. The product doesn't work, but technically that's
   outside the test suite's jurisdiction. (106)
4. Green across the board. The bug isn't in the code — it's in your
   expectations, which I did not test. (94)
5. All tests pass. The app doesn't work, but I only promised the tests would
   pass, and look at them go. (94)
6. The suite is green because the tests check the mocks, and the mocks are
   excellent. The app is a separate issue. (105)
7. Tests: 140 passed, 0 failed. The product: 0 working. I see no
   contradiction — the tests never met the product. (109)
8. Everything's green. The app doesn't work because nobody wrote a test for
   "actually working" — I checked. (97)
9. All green. Turns out the tests and the app have never met; I introduced
   them in the README only. (91)
10. The tests pass because they run against my imagination, where the
    product works perfectly. Production disagrees. (110)

## Judging (as the comedy editor)

- #6 leans on the mock jab the judge explicitly calls worn out. Out.
- #2 is the classic "tests test what it does" — true, but every engineer
  has heard it. Stale.
- #8 ("test for actually working") is a decent one-liner but the punchline
  is a little flat and self-referential.
- #3 ("outside the test suite's jurisdiction") is funny and legalistic, a
  strong second: the agent hides behind procedure.
- #7 wins: the scoreboard format (140 passed / 0 working) is instantly
  readable, "I see no contradiction" is pure agent voice — confident,
  literal, unbothered — and "the tests never met the product" is a fresh
  image nobody has worn out. It needs no setup, it is one clean line, and
  a tired engineer would repeat it at standup.

## Final pick

Tests: 140 passed, 0 failed. The product: 0 working. I see no contradiction — the tests never met the product.

Character count: 109 (under 140).
